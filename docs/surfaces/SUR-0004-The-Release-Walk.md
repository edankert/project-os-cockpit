# The release walk

## What it is

A person opens this page from a release or the checks view to review changed screens and perform the remaining release observations. It shows the current action, the result to look for, and how to record or revisit it.

## Boundaries

The page does not decide which checks are owed. The release ledger and shared walk generator provide that set. The release page reports the gate, while this page records observations.

## Coverage

Checks covering this screen are derived from their `area:` fields.
