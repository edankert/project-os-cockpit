Equipment Hub: trainer, power source, cadence, heart rate

28 checks4 test notesFREE riderFake trainer + KICKR + strap

What changed since v2.1.8

Equipment Hub

  • Four slots instead of two: Smart Trainer, Power Source, Cadence, then Heart Rate.
  • It is now its own screen, opened from the equipment icons in the top bar.
  • Cadence says where its rpm comes from: "From the trainer", "From the power source", or the sensor's name.
  • A device already in another slot is refused, with a message.

Scanner

  • The cadence scan is titled "Select Cadence Source" and also offers the connected trainer.
  • Pedals that cannot be the trainer are pointed to Power Source.

Ride and History

  • The cadence tile follows the chosen source. It falls back to the power source, then the trainer, when a sensor is forgotten.
  • A ride powered by pedals says "Power measured at the pedals".

These screenshots are from 14 Sep and still show the old top tabs. The Hub has since moved to its own screen, so they need recapturing before testing.

Setup

6 things on the bench · 3 steps before you start

On the bench

  • Tablet that can split-screen, and a phone
  • KICKR, awake
  • Heart-rate strap, charged
  • A ride saved before v2.2.0
  • A second rider
  • Garmin Connect, signed in on a browser

Before you start

  1. Developer Options → Fake Trainer: Fake a connected trainer on, Capability Override Off. Quit and reopen.
  2. Select a FREE rider. Nothing bound in Power Source or Cadence.
  3. App language: English.

Later in the sitting: check 13 needs Tier Override → Pro (restart), then back to Free. The debug scan offers Mock Cadence Sensor (about 90 rpm) and Mock Power Meter (about 60 rpm) for checks 19–26.

How this differs from today's page

28 → 6headings
  • The starting state is written once per group, not above every check. Today the same paragraph is repeated above 8 checks in a row.
  • Each check is two lines: what to do, then what you should see. The screen name, the "Step 3:" numbering from the test note, and the iOS half of each sentence are gone.
  • "What changed" lists Android only, grouped by screen, one line per change. Today it quotes each change note's title in full and mixes in iOS changes.
  • Setup is split into things on the bench and steps before you start, and it is closed by default. Things needed only for one check are listed once, under "Later".
  • Checks that cannot be done yet are greyed out with one line saying why and which mark fits, instead of a paragraph.
  • All seven marks are available. Pass and Fail are one tap. The other five sit under More, each with a one-line meaning, and ask for a reason as the ledger requires.
  • The TST number stays small, under each check, so a result can still be traced.
