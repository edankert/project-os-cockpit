# The survey method

## Definition of Done

- A skill under `tools/skills/harness-survey/` with the round's checklist: clone and read (source and tests, not the landing page), inventory capability against the problem each solves, classify take / adapt / decline, file each take as an issue or feature in the phase it belongs to, and record each decline in the not-taken list with its reason.
- The skill states the trigger rule explicitly — a round is event-driven, and a round with no filed output is a legitimate outcome worth recording.
- The 2026-08-05 t3.codes round is written up as its worked example, including the finding it produced about an unbuilt phase.
