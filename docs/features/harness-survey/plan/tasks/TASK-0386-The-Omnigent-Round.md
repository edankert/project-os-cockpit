# The Omnigent.ai round

## Why this is a task and not a paragraph somewhere

[[FEAT-0080]] exists precisely so that adjacent tools are mined **deliberately instead of whenever someone remembers**, and the round is *event-driven*: a new tool is one of the three named triggers. Omnigent.ai is that event. Filing it as a queued round is what the feature asks for; mentioning it in prose is the failure mode the feature was written against.

**Second surveyed harness, first repeat.** The t3.codes round ([[TASK-0342]]) was a one-off that paid for itself — four findings, one of them a hole in a phase that had not been built. This is the round that tests whether the method survives a second subject, which is the only way to find out whether [[TASK-0340]]'s skill is a method or a description of one afternoon.

## What is known about it right now: nothing

**Deliberately blank.** The method's first line is *read the code, not the marketing*, and nobody here has read either. Everything below is the shape of the round, not a finding — and this note claims no capability, no comparison and no verdict, because inventing one is worse than an empty section.

What is recorded is only the provenance: Edwin raised it on 2026-08-11 as a framework to consider beside t3.codes.

## Definition of Done

- The round is run to [[TASK-0340]]'s checklist: read source and tests rather than the landing page; inventory each capability against **the problem it solves**; classify take / adapt / decline.
- Every **take** is filed as an issue or feature in the phase it belongs to — not listed here.
- Every **decline** joins [[TASK-0341]]'s not-taken list *with its reason*. A round whose output is entirely declines is a legitimate outcome and is recorded as one.
- The round says explicitly whether the governance thesis survived contact: the cockpit is not competing on features, and a capability that does not serve *a person governing a project they did not write* is a decline however good it is.
- If the round finds a hole in an unbuilt phase — the thing the t3 round found and the reason the survey exists — that finding is filed against **that** phase, not here.

## Out of scope

Feature parity with Omnigent.ai, and any comparison written before the code has been read.
