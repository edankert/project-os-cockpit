Cockpit design system

Every value below is read from base.css, cockpit.css and the shell stylesheet as this page renders. Nothing is typed here, so nothing can drift.

Principles

Palette

Both schemes side by side, because the claim is that dark is designed rather than inverted — a toggle would hide exactly the comparison worth making. Neutrals are true greys so the accent is the only chroma and status colour reads as signal.

Status bands and severity — adjacent, deliberately

Status bands are categorical hues; severity is a ramp (red→orange→amber→grey). They are shown together so the rule is visible rather than asserted: never reuse one family's colour for the other — they answer different questions, and a reader who learns one mapping will misread the other.

Typography

Spacing & density

Measured from cockpit.css as this page loads — the counts below are computed, not quoted. Counted through the CSSOM, so shorthands are expanded and 0px resets are excluded; the figures therefore differ from a raw text count of the file, and this one is the live measurement.

Icons

The cockpit is near-iconless by default, and that is a choice. Status is a coloured dot plus a word; navigation is text; the mode strip is the one place carrying glyphs.

Rule: an icon may appear without a text label only when it is a persistent control whose position teaches its meaning — the mode strip, the terminal toggle. Anything appearing conditionally, or in a list, carries a word. A chip is a word with a colour, never a glyph alone.

Not shown here. The icon set lives in renderer.ts as inline SVG path data, not in any stylesheet, so this page cannot enumerate it without restating it — which is the one thing this page refuses to do. The rule above is the checkable part; the glyphs are in the mode strip at the top of the app.

Widgets

Real class names, styled by the real stylesheets. Each is shown in the states that must be distinguishable without colour — the property DES-0002 claims, which a rendered page can either prove or expose.

Motion

Almost nothing animates. The exceptions are attention signals with a decay: the rail dot pulses on needs-input, and the nav-row agent chip fades over ~8s. Motion is allowed only to say "this changed while you were not looking", and it must stop on its own — a tool read at a glance across a room cannot afford ambient movement competing with the one thing that needs a look.
