DES-0016 — Levels of abstraction

Plates for the design note beside this page. Seven levels, each addressed to a reader: the portfolio for whoever owns all thirteen projects, the project, the flow, the subject, the ticket, and two levels below the one anybody needs to build with — the evidence, and the machine trace.

Drawn dark by default; the shell's light scheme is the same tokens.

Nobody needs this level to run the project. It exists so that a wrong number on A1 can be chased to the request that produced it, the way an exemplar links a latency spike to one trace.

Evidence and trace. A5 answers "prove it": ledger verdicts with their captures, the commits that cite the feature, the validator and suite results, the raw frontmatter. A6 answers "which turn produced this": the agent's tool calls, the hook events, and the JSON payload the page was drawn from. Both are reached on purpose and neither is ever on screen by default.

Most true to "levels of abstraction": one gesture changes detail without changing subject, the way a map zooms. Needs every view to answer at every level, which is the work.

Option 3 — The level is a saved default

You choose where you usually stand; the cockpit opens there.

Cheapest way to serve several readers. The trap: one person is all four readers in one afternoon, so a role must be a remembered default, never an identity that hides levels.

The three mechanics, drawn small because the choice is about behaviour rather than layout. They are not exclusive: the recommendation is option 1's pages first, because they exist, then option 2's control across them, then option 3 as a remembered starting level.

The act that makes the number at A0 go down by one.

The contract: a number shown at any level is the count of rows the next level down can list, and selecting it lands on exactly those rows. A level may summarise; it may not compute anything the level below cannot enumerate.
What the contract would have caught: the fleet holds 263 features at an active status against 13 focus items — one project in flight each, and four projects with no focus feature at all. A portfolio tile reading "263 in flight" would be true of the record and false about the world. The overview's Tests 1 / 90 tile is the same defect already shipped: it counts a passing status that 34 of those 90 notes cannot carry.

The drill-down contract. Each number resolves downwards into the rows that produced it, until the bottom row is a thing a person can act on. The red panel is the failure this rule prevents, measured on 2026-09-20: counting the record's states instead of the world's work gives a portfolio number that is arithmetically correct and practically a lie.
